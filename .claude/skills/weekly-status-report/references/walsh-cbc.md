# Walsh CBC

Walsh CBC is the same **one-coordinate-at-a-time** search as integer CBC (`scripts/cbc_lattice.py`), run in the Walsh group instead of `ℤ/Nℤ`. Freeze `q1, ..., q(j-1)`, pick `qj` in `𝔽b[x]/(P)` (`references/polynomial-lattices.md`) to minimize a Walsh figure of merit. `scripts/cbc_fft.py` is the Fourier-`P2` cousin — it will not emit these `qj`, wrong algebra entirely.

## Setup

- Base `b` (usually 2), modulus `P ∈ 𝔽b[x]` of degree `m`, `N = b^m` points.
- Product weights `γj > 0`, smoothness `α` (even, typically 2).
- Figure: Walsh `P_α` (`references/walsh-digital-nets.md`) of the digital net generated by `(q1, ..., qp)`.

There's a product-form identity over the points, the Walsh analogue of the Bernoulli-kernel formula used for lattices:

```
P_α^Wal(q) = -1 + (1/N) Σ(n=0..N-1) Πj ( 1 + γj·ωα(x(n,j)(qj)) )
```

`ωα` is the **Walsh kernel** in one dimension — a piecewise-constant function of the base-`b` digits of `x`, not `B2`. `x(n,j)(qj) = νm(n·qj/P)`.

Smaller `P_α^Wal` is better. The dual-net sum over cheap Walsh modes is exactly this same number.

## The greedy loop

```
prod[n] ← 1 for n = 0..N-1
q1 ← 1                              # usual convention
update prod[n] *= 1 + γ1·ωα(x(n,1))
for j = 2..p:
    for each candidate q in F_b[x]/(P):
        score(q) = mean_n  prod[n] * (1 + γj·ωα(x(n,j)(q)))  - 1
    qj ← argmin score
    prod[n] *= 1 + γj·ωα(x(n,j)(qj))
```

Candidates: all polynomials of degree `< m`, or just the units if restricting to invertible `qj`. Tie-break: a fixed monomial order, smallest first.

After coordinate `j`, `prod[n]` is the product of the first `j` kernel factors at point `n` — identical in shape to the integer CBC running product in `scripts/cbc_lattice.py`.

## Where the FFT comes in

A naive score of one `q` is `O(N)`; `|𝔽b[x]/(P)| = N`, so one coordinate costs `O(N²)`. Fast Walsh CBC (Dick-Kuo-Sloan / Nuyens-style) rewrites the slice:

```
S(q) = Σn prod[n]·ωα( νm(n·q/P) )
```

as a convolution on the **additive group of the field** `𝔽(b^m)` (when `P` is primitive / irreducible). Identify `n` and `q` with field elements; `n·q` is field multiplication, and `S` becomes a multiplicative convolution. One character-FFT of `ωα ∘ νm` on that group, one FFT of the reindexed `prod`, pointwise multiply, inverse FFT: every `S(q)` at once, in `O(N log N)`.

That's the same trick as `scripts/cbc_fft.py`, with:

| | Integer FFT CBC | Walsh FFT CBC |
|---|---|---|
| Group | `{1,...,N-1}ˣ` for prime `N` | `𝔽(b^m)ˣ` or additive `𝔽(b^m)` |
| Kernel | `B2({ka/N})` | Walsh kernel `ωα(νm(nq/P))` |
| Output | `zj ∈ ℤ/Nℤ` | `qj ∈ 𝔽b[x]/(P)` |

A composite `P` is not a field. Some implementations still run against one anyway — but the convolution identity relied on may simply be false in that case. Say so explicitly if `P` isn't confirmed irreducible.

## What must not get reused from the integer code

- `B2` used in place of `ωα`.
- A primitive root modulo *integer* `N` used as the indexing group — wrong group entirely.
- Inverse-cdf into `Λ` applied *inside* CBC — that map only belongs **after** the net already exists (`references/qmc-rff.md`).
- Joe-Kuo `m(k,j)` (`references/joe-kuo.md`) used as candidates for `qj` — different search, different object.

Joe-Kuo is a different search entirely (2-D `t` + Property A on Sobol' seeds). Walsh CBC of a polynomial lattice is the group-shaped version of the same underlying idea, but a distinct construction.

## After `q` is chosen

Emit the net from `(P, q)`, apply a **digital shift** (`references/digital-shift.md`, not `{x+Δ}`), drop the origin if the shift left it at zero, map through `F_Λ⁻¹` for RFF. Freeze `(P, q, σ)` across all `q` Matheron draws in one BO step. Remap `ω` when `ℓ` changes; don't rerun CBC every BO step unless `γ, p, m` actually changed.

## Cost and when to bother

Direct Walsh CBC: `O(p·N²)`. FFT Walsh CBC: `O(p·N log N)` plus the cost of building `ωα` on the field. For RFF feature counts `N ≲ 2^10` and `p ≲ 16`, either is cheaper than a week of plant runs. For a 6-D GP, a published Joe-Kuo prefix is usually enough on its own; Walsh CBC earns its keep specifically when *weighted* coordinates are wanted (some spectral axes genuinely more important than others) or a net size that isn't a Sobol' prefix already on hand.

The algorithm ends at producing a good cube set. Bochner error (`references/rff.md`) only starts after `F_Λ⁻¹` is applied.
